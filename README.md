# GTA IV — DLAA + DLSS 5 Neural Rendering

A reproducible, version-pinned setup for running NVIDIA NGX DLAA in GTA IV, with optional DLSS 5 Neural Rendering via Deep Fried Chicken.

This repository contains the integration logic, configuration, ReShade/b-bridge input patch, verification notes, and installers. Third-party projects and NVIDIA runtimes should be downloaded from their original sources or supplied by the user.
